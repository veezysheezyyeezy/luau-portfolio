# Luau Systems Portfolio

This repository contains a static, GitHub Pages–ready portfolio showcasing advanced Luau systems. It's set up with a hacker-style (green-on-black) theme and five sample projects:

- Advanced Combat System
- Flight System
- Stealth & AI
- Vehicle / Driving System
- Parkour / Movement System

Each project page includes an architecture overview, annotated code snippets, and a downloadable example file in the `code/` folder.

How to use

1. Open the repository in your browser: https://github.com/veezysheezyyeezy/luau-portfolio
2. Enable GitHub Pages (if not already enabled) in Settings → Pages and select the `main` branch, root.
3. The site will be available at: https://veezysheezyyeezy.github.io/luau-portfolio/

Replace assets

Replace images in `/assets/` with screenshots or GIFs from your projects. Filenames used in the site: `combat.svg`, `flight.svg`, `stealth.svg`, `vehicle.svg`, `parkour.svg`.
