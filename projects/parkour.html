Parkour / Movement System

Ledge detection, vaulting, root-motion blending, and animation hooks for smooth parkour movement.

Overview

Parkour focuses on movement feel and robust detection. Ledge detection, vaults, and wall interactions are implemented with careful checks to avoid accidental triggers and provide predictable animation timing.

Architecture

  1. Contact detection: forward checks then downward samples for ledges
  2. Movement state machine: walking, running, jumping, wall-run, ledge-hang, vault
  3. Animation blending hooks: use event triggers to synchronize root-motion clips

Robustness & Tuning

  • Use small hysteresis windows to prevent flicker between states (e.g., ledge enter/exit).
  • Run collision checks at consistent intervals and prefer ray/box checks over per-frame physics where possible.
  • Tune animation lengths to match detection windows and use transition blending to hide corrections.

Example snippet (ledge detection)

-- cast forward then down to find ledge point
local function findLedge(origin, forwardDir, forwardDist, downDist)
  local forwardRay = Ray.new(origin, forwardDir.Unit * forwardDist)
  local hitPart, hitPos = workspace:FindPartOnRay(forwardRay)
  if not hitPart then return nil end
  local downStart = hitPos + Vector3.new(0,1,0)
  local downRay = Ray.new(downStart, Vector3.new(0,-1,0) * downDist)
  local groundPart, groundPos = workspace:FindPartOnRay(downRay)
  if groundPart then
    return groundPos
  end
  return nil
end
