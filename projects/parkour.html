Parkour / Movement System

Ledge detection, vaults, root-motion blending, and smooth transitions between states.

Key features

  • Ledge detection and auto-vault
  • Movement state machine: run, jump, wall-run, ledge-hang
  • Animation blending hooks for Studio

Example snippet (ledge detection)

-- cast forward then down to find ledge point
local function findLedge(origin, forwardDir, forwardDist, downDist)
  local forwardRay = Ray.new(origin, forwardDir.Unit * forwardDist)
  local hitPart, hitPos = workspace:FindPartOnRay(forwardRay)
  if not hitPart then return nil end
  local downStart = hitPos + Vector3.new(0,1,0)
  local downRay = Ray.new(downStart, Vector3.new(0,-1,0) * downDist)
  local groundPart, groundPos = workspace:FindPartOnRay(downRay)
  if groundPart then
    return groundPos
  end
  return nil
end
