Vehicle / Driving System

Wheel traction, suspension approximation, drift, and network smoothing for vehicles.

Overview

This vehicle system provides believable arcade-style driving with per-wheel forces, simple suspension, and drift behavior. It prioritizes stable visuals on the client while using server snapshots for authoritative state.

Architecture

  1. Per-wheel physics helpers (traction, slip, lateral force)
  2. Suspension spring-damper model per wheel
  3. Server reconciliation for position/velocity snapshots
  4. Client-side visual smoothing and wheel rotation interpolation

Network & Security

  • Transmit only compact state: position, linearVelocity, angularVelocity, steeringAngle.
  • Run lightweight server-side checks for impossible velocities/teleports.
  • For authoritative servers, re-simulate a small window of inputs to validate sudden changes.

Example snippet (suspension)

-- per-wheel spring force
local function suspensionForce(restLength, currentLength, springK, damperC, relativeVelocity)
  local displacement = restLength - currentLength
  local spring = springK * displacement
  local damper = damperC * -relativeVelocity
  return spring + damper
end
