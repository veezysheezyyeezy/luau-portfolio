Flight System

Client prediction, smooth damping, input smoothing, and camera follow improvements.

Key features

  • Input smoothing to avoid jitter
  • Client-side movement prediction with server reconciliation
  • Lift/drag approximation for arcade-style flight

Example snippet (input smoothing)

-- simple exponential smoothing for stick input
local alpha = 0.12 -- smoothing factor
local smoothed = Vector3.new()
function smoothInput(raw)
  smoothed = smoothed:Lerp(raw, alpha)
  return smoothed
end
