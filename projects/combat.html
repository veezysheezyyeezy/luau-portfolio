Advanced Combat System

Server-authoritative hits, combo system, predictive client animation, and AI reaction states.

Key features

  • Hit validation on server (ray checks + timestamp tolerances)
  • Combo windows and input buffering
  • Damage falloff, blocking, and stagger states
  • Simple AI for enemies with attack/evade/state machine

Example snippet (server-side hit validation)

-- server: validate hit from client
local function validateHit(attacker, targetId, reportedPosition, timestamp)
  -- basic checks: recent timestamp, distance limits
  if math.abs(os.time() - timestamp) > 2 then return false end
  local target = workspace:FindFirstChild(targetId)
  if not target then return false end

  -- perform a server-side ray/region check to ensure attack reaches target
  local origin = attacker.Character.Head.Position
  local direction = (reportedPosition - origin).Unit * 10
  local ray = Ray.new(origin, direction)
  local hitPart, hitPos = workspace:FindPartOnRay(ray, attacker.Character)
  if hitPart and hitPart:IsDescendantOf(target) then
    return true
  end
  return false
end
