Stealth & AI System

Sensing cones, alert levels, noise propagation, patrol graphs and scalable agent coordination.

Overview

This system models sight and hearing for NPCs, with layered alert states and propagation between nearby agents. It is designed to scale from a handful of NPCs to dozens by using cheap preliminary checks and only running expensive line-of-sight checks when necessary.

Architecture

  1. Per-agent sensing: cheap range checks followed by cone checks
  2. Line-of-sight gate: only when cone/range indicate possible detection
  3. Alert propagation: local area notifications (radius-based) to nearby agents
  4. Patrol graph: waypoint sequences with interruptible behaviors

Scalability & Optimization

  • Use spatial partitioning (quad/octrees or Roblox CollectionService tags with region checks) to limit pairwise checks.
  • Run expensive checks (raycasts) at staggered intervals across NPCs to avoid frame spikes.
  • Cache recent LOS results for short windows to reduce repeated raycasts.

Example snippet (sensing cone)

-- check if target is within sensing cone
local function inSensingCone(agentPos, agentLook, targetPos, angleDeg, range)
  local dir = (targetPos - agentPos)
  if dir.Magnitude > range then return false end
  local dot = agentLook.Unit:Dot(dir.Unit)
  local ang = math.deg(math.acos(math.clamp(dot, -1, 1)))
  return ang <= angleDeg/2
end
